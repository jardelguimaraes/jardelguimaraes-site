## 🚀 Deploy no Vercel

1. Suba este repositório no GitHub (branch `main`)
2. Acesse [vercel.com](https://vercel.com) → **Add New Project**
3. Importe o repositório `jardelguimaraes-site`
4. Framework: **Other** (sem framework)
5. Root Directory: `/` (raiz)
6. Clique **Deploy** — pronto!

### Domínio personalizado
No Vercel → Settings → Domains → adicione `jardelguimaraes.com.br`

### Bio no Vercel
Acessível em:
- `jardelguimaraes.com.br/bio`
- `jardelguimaraes.com.br/link`
